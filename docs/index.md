# Gaza Conflict Visualisation + Forecast Gallery

This site is generated by `acled-viz` and is built to track conflict dynamics in Gaza across space and time.

The storyboard combines spatial event points with a trailing window so shifts in conflict intensity are easier to read than cumulative plots alone.

## What This Site Is For

- Show where conflict concentrates, disperses, and re-concentrates over time.
- Compare short-term motion (days to weeks) against longer-run intensity.
- Provide reproducible visual artefacts from a single local ACLED cache.

## Data Coverage

- Current published gallery build in this repo uses Gaza ACLED fixture coverage from `2023-09-04` to `2024-12-04`.
- If ACLED credentials are configured, local full-mode builds can extend past that horizon.
